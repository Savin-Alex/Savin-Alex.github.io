_Пример PM-артефакта: статус-отчёт и решение «запускать или нет» по личному прототипу._

**Дата:** 2026-05-21 · **Статус:** прототип (рабочий локальный контур; не production).

## Кратко
Управляемый процесс разработки с AI: задача в Jira → план → код → проверка в изолированном контейнере → ревью человека → pull request в GitHub. Цель — показать AI в разработке как контролируемый процесс, а не «автогенерацию кода».

## Обязательные проверки до pull request
- Тесты и проверка стиля кода
- Изолированный контейнер без доступа к сети, только для чтения, с лимитами CPU и памяти
- Поиск секретов в коде перед созданием pull request
- Ревью человеком: система только **создаёт** pull request и не сливает его в основную ветку
- Лимит расходов на AI API

## Метрики
| Метрика | Значение |
|---|---|
| Прогоны на реальных Jira и GitHub | 8 прогонов (21 апреля 2026): 2 pull request с кодом из встроенного шаблона; прогон с Claude остановлен проверками (ошибка импорта) |
| Стоимость | учёт расходов по каждому прогону; прогон с Claude — около $0,01 |
| Что считается по каждому прогону | доля успешных прогонов · доля прошедших проверку в контейнере · доля повторов · время этапов · время до pull request |

_Данные для портфолио, а не замер в production._

## Главные риски
| Риск | Как снижаем |
|---|---|
| Небезопасный или неработающий код от AI | тесты, изолированный контейнер, одобрение ревьюера, повтор с исправлением |
| Утечка секретов в коде | поиск секретов; файл `.env` не попадает в контейнер |
| Неконтролируемый реальный запуск | по умолчанию пробный прогон; реальный — через отдельный контролируемый процесс в GitHub Actions |
| Превышение бюджета на AI | лимит расходов, метрика стоимости прогона |
| Неполный отчёт по прогону | summary.json, логи контейнера, снимок метрик, история по задаче |

## Отчёт по каждому прогону
`summary.json` · статусы этапов · снимок метрик · логи контейнера · история артефактов по задаче.

## Решение: запускать или нет
- ✅ **Для портфолио** (показ управляемого процесса) — да.
- ⛔ **Для production** — пока нет: нужны параллельное выполнение, дополнительные агенты (DevOps, документация), подготовка контейнеров для production и больше замеров.
- Честно: режим с AI включается флагом и по умолчанию выключен; без него работает встроенный шаблон. Прогон с Claude на реальных Jira и GitHub был один, остальные прошли на шаблоне.

## Следующие шаги
Панель метрик · матрица согласований (PM / техлид / безопасность / оператор) · шаблон отчёта об инциденте · больше замеров · публичный обезличенный набор отчётов.
