**2026 · Личный проект · Релиз-кандидат v0.5.0**

PII Firewall — расширение Chrome для пользователей AI-чатов (ChatGPT, Claude, Gemini, Perplexity, Poe). Оно маскирует персональные данные в браузере до отправки запроса и восстанавливает их в ответе локально.

Это часть семейства из трёх продуктов: ту же задачу решают офлайн-движок [Local PII Anonymizer](./local-pii-anonymizer.html) и веб-приложение [RemovePII](./removepii.html) на его основе, а у PII Firewall собственный движок и нет доступа к сети.

## Задача

Люди вставляют в AI-чаты договоры, документы и банковские реквизиты. Облачные фильтры персональных данных предлагают доверить те же данные ещё одному серверу. Пользователю нужна защита, которая срабатывает до того, как данные покинут страницу, и обещание приватности, которое можно проверить самому.

## Мой вклад

**IT Project Manager, продукт выполнен в одиночку: постановка задачи, архитектура, разработка и подготовка релиза.**

- Выбрал работу без доступа к сети главным обещанием продукта и ограничил разрешения расширения до `storage`, `activeTab` и `contextMenus`.
- Разработал движок распознавания на TypeScript без внешних зависимостей.
- Задал уровни уверенности для каждого типа данных: число без контекста не маскируется так же уверенно, как номер с верной контрольной суммой.
- Подготовил выпуск в соответствии с политиками Chrome Web Store User Data и Limited Use.

## Результат

**Расширение распознаёт 36 типов данных без единого сетевого разрешения; для Chrome Web Store собран пакет v0.5.0.**

- Без сетевых разрешений расширение не может никуда отправить данные; любой может проверить это в `manifest.json`.
- Распознавание проверено на синтетическом корпусе с «ловушками» — похожими значениями, которые маскировать не нужно. Реальные персональные данные не использовались.
- Статус — релиз-кандидат: пакет и чеклист для магазина готовы. Новые детекторы для Великобритании, MRZ, Китая и ОАЭ ещё не выпущены.

## Дальнейшее развитие

Следующий шаг — публикация в Chrome Web Store и сбор жалоб пользователей на ложное маскирование и пропуски. Будущий платный командный режим спроектирован как отдельная сборка на сервере команды, чтобы бесплатная версия осталась без доступа к сети.

<details markdown="1"><summary>Подробности: решения и риски</summary>

- Распознавание имён основано на эвристиках, поэтому имена могут быть пропущены; адреса расширение не распознаёт.
- Расширение не является сертифицированным средством защиты информации; README и карточка магазина говорят об этом прямо.

</details>
