## Кейсы

- **[TripGPT](projects/tripgpt.md)** — AI-планировщик поездок для сайта и Telegram: подбирает дорогу и отель, составляет маршрут по дням и меняет поездку в диалоге. Хакатон Островка, 2026. Результат: от запроса до плана поездки с проверкой бюджета и расписания.
- **[Голосовой ассистент для записи в клинику](projects/medoperator-ai.md)** — запись, перенос, отмена и напоминания о приёме; перед изменением записи ассистент получает подтверждение пациента. Хакатон «Точка сборки», 2026. Результат: 13 из 20 демозвонков прошли без участия человека при цели 60%.
- **[Multi-Agent AI Development Pipeline](projects/ai-dev-pipeline.md)** — процесс от задачи в Jira до pull request в GitHub на трёх AI-агентах; каждый прогон проходит тесты, поиск секретов и ревью человеком. Результат: прототип доводит задачу из реальной Jira до pull request.
- **[AI Consul](projects/ai-consul.md)** — десктоп-ассистент для собеседований и встреч: расшифровывает речь в реальном времени и подсказывает ответы. Результат: максимальная задержка снизилась с 23 с до менее 1 с, зависания — с 15 до 0.
- **Защита персональных данных для AI** — персональные данные заменяются метками до отправки текста в AI-сервис и возвращаются в ответе. Три продукта: [Local PII Anonymizer](projects/local-pii-anonymizer.md), [RemovePII](projects/removepii.md), [PII Firewall](projects/pii-firewall.md). Результат: macro F1 0.9997 на синтетических данных.
- **[DVPhoto.me](projects/dvphoto.md)** — веб-сервис проверки фото для визовой лотереи США: 32 проверки по официальным требованиям и автоматическое исправление кадрирования и размера файла. Работает на [dvphoto.me](https://dvphoto.me). Результат: проверен на 763 фото.
- **[Telegram AI News](projects/telegram-ai-news.md)** — пайплайн русскоязычного Telegram-канала про ИИ: собирает новости из 56 источников, отбирает важные с помощью LLM и публикует посты автоматически. Канал: [«ИИнтересные новости»](https://t.me/ainews24by7).
- **[Mood&Food](projects/mood-food.md)** — PM/BA-кейс мобильного приложения для сети ресторанов: устав, требования, бэклог по MoSCoW, roadmap, смета и Figma-прототип. Результат: смета MVP 5,27 млн ₽, 40+ функций по приоритетам, защита перед комиссией.
